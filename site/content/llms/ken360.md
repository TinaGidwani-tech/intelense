# Ken360 — The Unified AI Platform

> One platform connecting all six Ken modules. One API, one dashboard, complete operational visibility across every AI capability Intelense offers.

**URL:** https://www.intelense.com/ken360

## What Ken360 Does

Ken360 is the unified intelligence engine that powers all six Ken modules — KenVision, KenSafety, KenHome, KenAgri, KenIoT, and KenRobotics. Instead of six separate systems, organisations get one shared data model, one API, and one dashboard for complete cross-domain visibility.

## Core Architecture

- **Unified Data Model** — All modules share a common data schema for cross-domain correlation
- **Single API** — One integration point for all six AI capabilities
- **Unified Dashboard** — Live views across safety, footfall, crop health, IoT, and robotics from one screen
- **Edge + Cloud** — Processing at the camera/sensor edge for real-time speed, synced to cloud for analytics
- **Modular Deployment** — Start with one module, add others without re-integration

## Key Stats

- 6 AI modules on one platform
- Deploys in days, not months
- Edge + cloud hybrid architecture
- One API for all integrations

## Why Ken360

Organisations running multiple Intelense modules benefit from cross-domain intelligence — for example, correlating retail footfall (KenVision) with staff safety compliance (KenSafety) in the same store, from the same dashboard, through the same API.
